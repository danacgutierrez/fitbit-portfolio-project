## About the Dataset
**Source:** [FitBit Fitness Tracker Data](https://www.kaggle.com/datasets/arashnic/fitbit?resource=download-directory)
(Kaggle, user arashnic) — CC0: Public Domain.

Data collected by a distributed survey via Amazon Mechanical Turk between 
03.12.2016-05.12.2016, from 30+ Fitbit users, including daily physical activity, 
sleep, and heart rate.

**Files used in this first version:**
- `dailyActivity_merged.csv` — steps, distance, minutes per activity level,
  calories, per user per day.
- `minuteSleep_merged.csv` — minutes asleep, time in bed, per user per day.

The per-minute heart rate file was left out of this version to avoid
unnecessarily complicating the data merge. This may be revisited later if
the final research question requires it.
